# Git Automation Rule

Whenever you make changes to files, write new code, or fix bugs in this workspace, you MUST automatically commit and push the changes to GitHub using your `run_command` tool. 

Do not ask the user to manually run `git push` commands. Do it yourself.

Use the following commands whenever you complete a task:
```bash
git add .
git commit -m "update: [descriptive message]"
git push
```
